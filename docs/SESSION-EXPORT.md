# 工作区 AI 会话证据导出

为保留比赛要求的 AI 对话记录，在会话视图顶部点击 **导出工作区会话**。一次操作生成并下载 `.tar.gz`，同时在宿主 `reportDir/session-exports/` 保存权限为 `0600` 的副本。

导出范围是当前主会话所在工作区的全部可发现会话、其后代，以及题目记录关联的解题、复核、蜂群和任务会话。不是整台机器的全部对话。每道题独立一个文件夹：

```text
workspace-工作区名-摘要/
  manifest.json
  README.txt
  _shared/
    sessions/
      会话摘要.header.json
      会话摘要.events.jsonl
    attachments/
  challenge-第一题-摘要/
    challenge.json
    statement.md
    session-index.json
    sessions/
      子代理会话摘要.header.json
      子代理会话摘要.events.jsonl
    attachments/
  challenge-第二题-摘要/
    ...
```

会话文件名和题目目录附带稳定摘要，避免同名覆盖与路径穿越。跨题共用的主会话、会话附件只保存一份；各题 `session-index.json` 列出自身子会话和共用主会话的归档路径。图片保留宿主存储的原始编码字节；作为文件附件上传的视频等通过文件流读取，保留字节和文件扩展名。这里不会另行录制屏幕或生成视频。

## 原始记录与完整性

每条原始会话事件独立一行写入 JSONL，保留全部事件种类，包括用户消息、模型回复、工具参数、工具输出、请求上下文和分支信息。不会将记录压缩成摘要或只保留最终回复，也不自动脱敏。文件可能包含对话中已经出现的凭据或其他敏感内容，提交前需按比赛规则自行检查。

`manifest.json` 包含工作区、导出起止时间、会话父子关系、继承事件数、事件数量、附件关联、各会话和附件文件的 SHA-256、缺失说明。`complete` 只表示这次发现和读取没有报告缺失；它不能补回宿主没保存、已删除或未提供的记录，也不代表比赛方已认可材料。

活跃会话导出的是时间点快照。导出时会先调用宿主持久化刷新；发现会话在导出期间新增事件或工作区仍有运行/排队任务时，会明确标为需再次导出的快照。比赛结束后建议生成最终版本。

已知子会话缺失、持久化目录不可读、附件缺失/不支持、事件不连续、刷新失败，都会出现在清单中，并通过下载后的通知提示“有缺失或快照说明”。不会静默截断记录并标为完整。若没有成功读取任何原始会话，则直接报错，不生成空证据包。

## 宿主接口与边界

导出通过 DSH 的 `sessions`、`sessionPersistence` 与 `attachments` 服务读取，不猜测宿主 JSONL 的磁盘目录，也不直接解码某个版本的 Zstandard 文件。当前持久化接口使用 `list()`、`flush()`、`open(id, 'read')`、`handle.read()` 和 `close()`；兼容完整事件数组和 `{events}` 返回形式。旧宿主缺少持久化服务时仅尝试完整内存事件，并明确标为不完整。接口完全不可用则报错。

图片通过 `attachments.readImage` 读取，文件通过 `readFileStream` 读取。未联网下载外部引用，不根据工具输出中的任意路径读取本机文件。外部/旧格式图片引用会保留在事件中并列出未打包说明。工具自身早已截断的输出只能保留宿主实际记录的版本。

仅有效主会话可发起导出，开始、逐会话读取和写文件前会重复核对工作区。全部工作区只读模式下按钮禁用。下载端点 `POST /dsh-ctf-auto/sessions.export.download` 使用现有同源检查与 CSRF 校验；客户端不能指定源目录、任意会话 ID 列表或输出路径。

归档原始数据上限 256MiB，单附件上限 64MiB，最多 1000 个会话、单会话最多 100 万条事件。超限会拒绝或在缺失清单中明确标注，不静默截断。导出目录拒绝符号链接；归档通过排他创建并刷新到磁盘后返回。

验证包括：原始事件与工具输出保持、历史后代收集、工作区隔离、附件字节与摘要、缺失回执、句柄关闭、输出目录安全、逐题目录结构、HTTP 下载权限和浏览器一键下载。真实 DSH 安装版本仍需确认其上述服务接口可用；导出后应检查清单及实际 JSONL 内容。
