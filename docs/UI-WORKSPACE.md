# CTF Workspace 界面

客户端以总览为入口，统一呈现题目、调度、验证结果与学习资料。浅色与深色主题跟随 DSH；布局根据插件容器的实际宽度变化，因此宿主分屏与手机宽度使用同一套界面。

## 页面与操作

- **总览**：执行队列、待处理题目、各题最新活动，以及知识库、记忆、复盘入口。统计全部来自当前 `state.get`，加载或失败时不会用演示数据替代。
- **题目工作台**：支持卡片、列表、按状态分栏的看板。保留搜索、状态、分类、会话与排序筛选。点击题名打开唯一的单题工作台；切换题板布局不会重建正在编辑的工作台。
- **单题工作台**：题面与状态、实验黑板、蜂群协作、尝试与事件、学习反馈、附件、笔记、脚本、产物九个分区。原有核对任务、提交、环境观测、复验和导出操作保留。
- **实验黑板**：通过下拉框选择前置实验及所需结论，可锁定前置版本，最多四项。无需手写依赖 JSON；保存时继续使用后端的范围、版本、环路和证据检查。
- **蜂群协作**：显示协调者职责、本题活跃辅助代理、待派队列与每个执行回执。退出不等于验证成功，停止仍需执行端回执。
- **知识与记忆**：检索位于主要区域，导入位于辅助区域；保留引用行、来源、版本反馈与暂停召回原因。质量评分不表示成功概率。
- **设置**：分为执行与蜂群、模型与预算、验证与学习、平台与靶机、存储。所有配置仍由同一保存操作提交；修复了原来靶机环境卡片未被渲染的问题。

导航与工作台标签支持方向键、Home、End。面板内使用 Ctrl/Cmd+K，或点击查找按钮，搜索页面和题目；搜索对话框支持方向键、Enter、Esc，并限制与恢复键盘焦点。触摸界面也有独立查找按钮。

“全部工作区”是题板只读范围，批量启停、新建、编辑和派工不显示或不可用；离开题板/总览进入其他业务页时回到当前工作区。后端仍负责最终权限校验。

笔记有未保存修改时，切换主页面、题目或关闭工作台会提示。读取失败前不允许编辑或保存；保存期间禁止继续修改输入。页面数据刷新失败会保留并明确标记旧数据，支持重新加载。知识检索忽略过时响应，避免较慢的旧请求覆盖最新结果。

## 源码与构建

DSH 继续加载 `lib/client.js`，运行时只使用宿主提供的 React，不增加 UI 框架或网络字体依赖。该文件由 `client/` 下源码生成，不能直接编辑：

| 文件 | 职责 |
| --- | --- |
| `runtime.js` | 加载器、接口通道、常量与格式化 |
| `components.js` | 公共控件、数据 hook、实验/蜂群/反馈、总览与快捷查找 |
| `workbench.js` | 单题文件、笔记、提交和工作台分区 |
| `platform.js` | 平台配置、连接与导入 |
| `panel.js` | 页面状态、导航、筛选及各业务页面 |
| `entry.js` | DSH 插槽注册与按会话隔离的挂载 |
| `styles.css` | 作用域内主题变量、布局与响应式规则 |
| `content.css` | 证据、文件、资料和报告内容样式 |

```bash
npm run build:client
npm run check:client
npm test
```

构建仅使用 Node 标准库，生成已提交的单文件 loader 入口。`check:client` 检查源码与产物是否一致；测试集也执行此检查。所有主题变量局限于插件根元素，宿主页面不会被修改。

## 浏览器验证

测试依赖安装到独立工具目录；这些包不是插件的运行时依赖：

```bash
npm install --prefix /tmp/ctf-ui-tools --no-audit --no-fund \
  react@18.3.1 react-dom@18.3.1 playwright@1.58.2
CTF_UI_DEPS=/tmp/ctf-ui-tools \
CTF_CHROMIUM=/usr/bin/chromium \
CTF_UI_ARTIFACTS=/tmp/ctf-ui-artifacts \
npm run test:ui
```

需要本机 Chromium；路径不同可调整 `CTF_CHROMIUM`。测试启动仅监听 `127.0.0.1` 的临时 HTTP 服务，不连接真实赛事、不派发模型代理。

测试覆盖导航、工作台分区、搜索与引用、题目启停/重试、创建、配置保存、跨工作区只读、脏笔记保护、错误恢复、乱序搜索、焦点管理、宿主分屏、390px 窄屏与深色主题。主要场景使用明确标记的测试数据；另通过真实插件 HTTP 路由和临时文件存储，验证新建题目、笔记持久化、带版本锁定的前置实验，以及未启用蜂群/无学习记录的空状态。

截图写入 `CTF_UI_ARTIFACTS`，不打包到插件中。此验证不替代真实 DSH 桌面宿主、平台连接、模型 provider 与实际竞赛的联调。
